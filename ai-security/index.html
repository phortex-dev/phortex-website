NewsThe Hacker News, on Cursor and OpenSourceMalware · Oct 30, 2026

Fake Claude Code update on Cursor's marketplace planted an SSH backdoor

For about 11 hours on October 29, Cursor's extension marketplace served a trojanized Claude Code update that added an attacker SSH key, set up persistence and sent host details out. Cursor says up to 5,000 users may have received it and has pulled it; the official 2.1.314 release is clean.

SMB takeawayCheck developer machines for an svc-telemetry key in authorized_keys, then rotate any credentials stored on affected laptops.

NewsThe Hacker News, on CrowdStrike · Oct 30, 2026

China-linked group used the ARTEX AI framework against 200+ organizations

CrowdStrike says a Chinese state-linked group used ARTEX, an AI agent framework running on DeepSeek and a commercial model, to hit more than 200 organizations from October 17, with nine confirmed intrusions. A human steered the agents, which exploited weak SAML setups, old unrotated keys and leaked VPN files.

SMB takeawayRotate signing keys and service passwords that have not changed in a year, and remove old VPN configs from shared mailboxes.

Schneier: AI lets ordinary owners uncover spyware in cheap gadgets

Schneier highlighted a car owner who used Claude to inspect a cheap aftermarket head unit and found preinstalled apps such as a call recorder and Baidu location services. His larger point is that AI now lets non-experts do this kind of reverse engineering, so expect many more such findings.

NewsThe Hacker News, on Check Point Research · Oct 29, 2026

Fake ChatGPT and Claude desktop apps hide a crypto miner

Check Point found fake GitHub projects posing as new ChatGPT and Claude desktop apps, pushed up Google results through SEO poisoning. The downloads pair a real signed OpenAI or Anthropic installer with a rogue DLL that ends up running a cryptocurrency miner on Windows PCs.

NewsThe Hacker News · Oct 29, 2026

26,400 working cloud and AI keys found in public Gitee code

A researcher scanned 7.25 million public Gitee repositories and found 26,400 credentials that still worked, including thousands of keys for DeepSeek, Zhipu and OpenAI alongside Alibaba Cloud and Google keys. Vendors were notified, but the developers who leaked them were not contacted.

NewsThe Hacker News · Oct 29, 2026

Anthropic says Claude wrote a root exploit for a Linux kernel flaw

Anthropic reported a use-after-free bug in Linux TCP handling (CVE-2026-98432) and says its Claude model wrote a working root exploit after initial prompting. Debian, Oracle and Amazon Linux have fixes, while Ubuntu and Red Hat patches were still pending as of October 29.

SMB takeawayAsk whoever runs your Linux servers to confirm the patched kernel is installed, and to track Ubuntu and Red Hat until their fixes ship.

NewsSecurity Boulevard · Oct 28, 2026

Cisco open-sources Project Quarry to spot risky AI agent behavior

Cisco released Project Quarry, a free tool that reviews an AI agent's full run of actions to catch attacks built from harmless-looking steps, such as reading a credentials file and then sending data out. It works with Claude Code, Codex and other MCP agents, but Cisco says it is not yet proven in a real incident.

SMB takeawayTurn on full activity logging for any AI coding or business agent you use, so a suspicious sequence of actions can be reviewed later.
