Docker Sandboxes flaw let AI agents reach files outside their sandbox

Endor Labs found that the copy command in Docker Sandboxes followed symbolic links, so an agent could plant a link and read or overwrite files on the developer's machine, such as cloud keys. Docker fixed it in version 0.51.0 after an earlier fix proved incomplete.

SMB takeawayUpdate Docker Sandboxes to 0.51.0 or later, and read any file-copy command an AI agent suggests before you run it.

NewsThe Hacker News, on Chainstack · Nov 3, 2026

Chainstack breach exposes customer data in a suspected AI-driven campaign

Blockchain infrastructure provider Chainstack said an attacker got in through a third-party component, moved from a development system into production, and read customer names, emails and password hashes. It is assessed as part of the AI-powered campaign linked to breaches at Chainalysis and WorkOS.

SMB takeawayKeep development and production systems on separate accounts and credentials, so a break-in at a test server cannot reach customer data.

NewsThe Hacker News, on Binance · Nov 3, 2026

Binance traces its 6.43 billion dollar theft to fake job interviews and an abused internal AI tool

Binance said attackers infected one engineer through a fake job interview assignment and another through a trojanized AI tool installer, then abused an internal AI tool to reach colleagues' machines. From there they used a deployment token to reach the wallet signing service.

SMB takeawayTell staff never to run job interview assignments or newly downloaded AI tools on work computers, and install AI tools only from the vendor's official site.

NewsHelp Net Security, on Kaspersky research · Nov 3, 2026

AI agent framework took attackers from a school server to domain admin in days

Kaspersky saw attackers use the open-source CyberStrikeAI framework against schools and universities in Africa and Latin America, with an AI model on their own server picking each next step. After a manual break-in through SQL Server, the agent mapped the network in hours and reached domain admin in three to four days.

SMB takeawayClose internet access to database servers such as SQL Server and set alerts for credential dumping and Kerberoasting, which AI-driven attacks still rely on.
