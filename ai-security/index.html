NewsThe Hacker News, on Check Point Research · Oct 29, 2026

Fake ChatGPT and Claude desktop apps hide a crypto miner

Check Point found fake GitHub projects posing as new ChatGPT and Claude desktop apps, pushed up Google results through SEO poisoning. The downloads pair a real signed OpenAI or Anthropic installer with a rogue DLL that ends up running a cryptocurrency miner on Windows PCs.

SMB takeawayAllow AI desktop apps only from the vendor's official download page, and block installs from GitHub links found through search.

NewsThe Hacker News · Oct 29, 2026

26,400 working cloud and AI keys found in public Gitee code

A researcher scanned 7.25 million public Gitee repositories and found 26,400 credentials that still worked, including thousands of keys for DeepSeek, Zhipu and OpenAI alongside Alibaba Cloud and Google keys. Vendors were notified, but the developers who leaked them were not contacted.

SMB takeawayRevoke any AI or cloud key that ever sat in a code repository, then set spend limits on every AI provider account.

NewsThe Hacker News · Oct 29, 2026

Anthropic says Claude wrote a root exploit for a Linux kernel flaw

Anthropic reported a use-after-free bug in Linux TCP handling (CVE-2026-98432) and says its Claude model wrote a working root exploit after initial prompting. Debian, Oracle and Amazon Linux have fixes, while Ubuntu and Red Hat patches were still pending as of October 29.

SMB takeawayAsk whoever runs your Linux servers to confirm the patched kernel is installed, and to track Ubuntu and Red Hat until their fixes ship.
